================================================================
               NarraFork macOS Launcher (Apple Silicon)
                         客户端安装与使用说明
================================================================

一、 安装方法
  1. 将左侧的「NarraFork」应用图标直接拖拽到右侧的「Applications」文件夹中；
  2. 拷贝完成后，从「访达 -> 应用程序」或「启动台 (Launchpad)」中直接打开 NarraFork 即可。

二、 首次打开安全提示（重要）
  由于本应用为本地编译打包（未经过 Apple 付费开发者证书公证），macOS 系统
  在初次打开时可能会弹出安全提示：
  “无法验证开发者” 或 “已损坏，无法打开。您应该将它移到废纸篓”。

  【解决方法（任选其一，只需操作一次）】：
  • 方法 1（推荐·右键打开）：
    在「应用程序」文件夹中，按住 Control 键（或右键）点击 NarraFork 图标，
    在菜单中选择「打开」，并在弹出的确认对话框中再次点击「打开」即可。
  • 方法 2（终端命令解除）：
    打开 Mac 自带的「终端」，粘贴并运行以下命令后回车：
    xattr -cr /Applications/NarraFork.app

三、 纯净加载与数据安全
  • 本应用完全内嵌了官方完整的离线核心后端，开箱即用，无需预装 Node 或 Python；
  • 本应用为纯净加载器，内置就绪纯净模板，绝不包含任何他人项目、历史聊天或 API Key；
  • 首次启动会自动进入初始化向导，由你自行设定管理员账号密码；
  • 你的所有数据与配置文件 100% 存储于你本机个人主目录 (~/.narrafork/)，数据完全私有隔离。

四、 无缝热更新特性
  • 当界面提示有新版本并点击下载更新后；
  • 仅需点击屏幕顶部菜单栏 NarraFork 图标中的「重启核心服务」（或重新启动 App）；
  • 原生加载器将在后台自动无缝热替换为最新版本，无需重新打包或寻找文件！
